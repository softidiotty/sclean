**Очистка и оптимизация Windows в одном окне.**

Чистит диск, настраивает систему под непрерывную работу и показывает состояние железа. Делалась под моноблоки и планшеты с iikoFront, подходит для любой машины на Windows 10/11.

Отмечаете нужные пункты → нажимаете «Выполнить всё отмеченное». Рядом со списком видно, сколько пунктов отмечено и сколько это займёт, а строка поиска фильтрует список по названию и описанию. Перед изменением настроек состояние сохраняется в бэкап — вернуть можно одной кнопкой. Права администратора запрашиваются при старте.

## 📊 Видно сразу при запуске

Собирается автоматически, запускать ничего не нужно.

| | Что показывает |
|---|---|
| 💾 **Диск C** | Полоса заполнения и цифры. Краснеет от 85%, от 90% — предупреждение с кнопкой «Очистить сейчас». Клик — открыть в проводнике |
| 🖥 **Система** | ОС, сборка Windows, процессор, память, видеокарта, материнская плата |
| 🩺 **Диагностика** | Аптайм, процессор, память, видеокарта, накопители (SMART, температура) |
| 📋 **Журнал событий** | История сбоев за 30 дней — собирается только по кнопке «Собрать» |
| 🚀 **Автозагрузка** | Открывает обе папки автозагрузки — удаляете сами |

### ⚠️ Требует внимания

Проблемы выносятся отдельным списком:

| Проблема | Порог |
|---|---|
| 💽 Состояние диска не Healthy | — |
| 🌡 Перегрев диска | от 60 °C |
| 🌡 Перегрев процессора | от 85 °C |
| 📉 Мало места на разделе | меньше 10% |
| 🧠 Память занята | больше 90% |
| 🎮 Видеодрайвер не установлен | базовый адаптер Microsoft |
| 📺 Сбои видеодрайвера | хотя бы один за 7 дней |
| ❌ Видеоустройство с ошибкой | код 43, 31 и подобные |
| ⏱ Давно не перезагружался | больше 14 дней |
| ❗ Ошибки теста памяти Windows | — |

### 📋 Журнал событий

Собирается только по кнопке «Собрать» — на слабых машинах чтение журнала за месяц может занять до минуты, поэтому автоматически не запускается. Показывает за последние 30 дней: некорректные выключения, синие экраны, падения и зависания приложений, число запусков системы. Отклонения выносятся отдельно:

| Проблема | Порог |
|---|---|
| ⚡ Некорректные выключения | от 5 за месяц |
| 💥 Синий экран | хотя бы один |
| 📛 Падения приложений | от 20 за месяц |
| 🔁 Частые перезагрузки | больше 2 в день |

## 🛠 Пункты обслуживания

### 🧽 Очистка

| Пункт | Что делает |
|---|---|
| **Временные файлы, логи и кэши** | TEMP, логи CBS и DISM, Prefetch старше суток, отчёты WER, кэш миниатюр и обновлений |
| **Корзина** | Полная очистка, объём замеряется до удаления |
| **Очистка диска (cleanmgr)** | Встроенная очистка Windows по быстрым категориям |
| **Глубокая очистка обновлений** | Старые обновления, предыдущие установки, ESD, WinSxS через DISM |
| **Старые точки восстановления** | Удаляет теневые копии, оставляя свежую |

> 💡 **Глубокая очистка** освобождает больше всего места (часто 3-10 ГБ), но работает долго — обработку ведёт `TiWorker.exe`. В рекомендуемый набор не входит.

### 🔍 Проверка

| Пункт | Что делает |
|---|---|
| **`sfc /scannow` + DISM** | Восстановление целостности системных файлов. 10-30 минут |
| **Оптимизация диска C** | TRIM для SSD, дефрагментация для HDD — тип определяется сам |
| **Скорость интернета** | Через Speedtest CLI или скачиванием тестового файла |

### ⚙️ Настройки системы

| Пункт | Что делает |
|---|---|
| **Электропитание** | Высокая производительность + запрет сна, гашения экрана и отключения дисков |
| **Визуальные эффекты** | Отключает анимации и тени, ClearType остаётся |
| **Брандмауэр** | Отключает во всех трёх профилях |
| **Ненужные службы** | 13 безопасных служб. Кнопка «Подробнее» — включить/отключить каждую отдельно |
| **Энергосбережение USB** | Снимает галочку отключения портов через WMI + запрет на уровне системы |

> 🔌 **Энергосбережение USB** нужно, чтобы не отваливались сканеры штрихкодов, чековые принтеры и прочая периферия.

## 💾 Бэкап

Перед изменениями состояние пишется в `sclean_backup.json`. Кнопка «Бэкап» даёт выбрать, что вернуть:

`Электропитание` · `Брандмауэр` · `Визуальные эффекты` · `Службы Windows` · `Энергосбережение USB`

> ⚠️ Удалённые файлы не восстанавливаются — операция необратима.

---

## 📄 Отчёты

Пишутся в `Рабочий стол\sclean` после каждого запуска. Итог сверху, затем построчно по каждому пункту: что очищено, включено или отключено и почему. Хранятся последние 30, старые удаляются сами.

> ℹ️ Освобождённое место — сумма того, что пункты измерили сами. Объём от встроенной «Очистки диска» сюда не входит: cleanmgr не сообщает его программам.

## 📦 Сборка

```bash
pip install pyinstaller
pyinstaller sclean.spec
```

Готовый `sclean.exe` появится в `dist`. Иконка, логотип и запрос прав администратора уже прописаны в `sclean.spec`.

Релизы собираются автоматически при пуше тега вида `v1.2.3` — см. `.github/workflows/release.yml`.

## 🔄 Обновление

Кнопка «Проверить обновление» смотрит последний релиз на GitHub, скачивает и ставит его — программа заменяет свой exe и перезапускается сама.

<details>
<summary>🖼 Иконка отображается старой?</summary>

Windows кэширует иконки. После обновления файла:

```bash
ie4uinit.exe -show
```

Либо перезапустить проводник в диспетчере задач.

</details>
