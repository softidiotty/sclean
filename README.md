# sclean

Программа с графическим интерфейсом для обслуживания компьютеров на Windows: чистит диск, настраивает систему под непрерывную работу и показывает состояние железа. Делалась под моноблоки и планшеты с iikoFront, но подходит для любой машины на Windows 10/11.

Работает так: отмечаете нужные пункты списка (или запускаете каждый по отдельности кнопкой «Выполнить») и нажимаете «Выполнить всё отмеченное». Перед изменением любых настроек текущее состояние сохраняется в бэкап — вернуть обратно можно кнопкой «Бэкап». Программа запрашивает права администратора при старте: без них большинство операций Windows не разрешает.

## Что показывает сразу при запуске

Эти данные собираются автоматически, ничего запускать не нужно.

**Заполнение диска C** — полоса и цифры «занято / всего (%)». Подсвечивается красным при заполнении от 85%. Клик открывает диск в проводнике.

**Сведения о системе** — ОС, номер сборки Windows, процессор, объём памяти, модель материнской платы. Копируются кнопкой или выделяются мышью.

**Диагностика железа** — сворачиваемый блок:

- время работы без перезагрузки и дата последней загрузки;
- процессор: ядра, частота, загрузка, температура;
- память: занято, модули, частота, результат встроенного теста Windows;
- накопители: объём, тип, состояние SMART, температура.

Найденные проблемы выносятся отдельным списком «Требует внимания»:

| Проблема | Порог |
|---|---|
| Состояние диска не Healthy | — |
| Перегрев диска | от 60 °C |
| Перегрев процессора | от 85 °C |
| Мало места на разделе | меньше 10% |
| Память занята | больше 90% |
| Давно не было перезагрузки | больше 14 дней |
| Ошибки встроенного теста памяти | — |

**Автозагрузка** — открывает обе папки автозагрузки в проводнике (текущего пользователя и всех пользователей). Программа ничего не удаляет сама, решение остаётся за вами.

## Пункты обслуживания

### Очистка

**Очистка временных файлов, логов и кэшей**
Временные файлы пользователя и системы, логи CBS и DISM, старый Prefetch (только файлы старше суток), отчёты об ошибках WER, кэш миниатюр проводника, кэш обновлений Windows.

**Очистка корзины**
Полностью очищает корзину, объём замеряется до удаления.

**Очистка диска (cleanmgr)**
Встроенная «Очистка диска» Windows по быстрым категориям. Тяжёлые категории вынесены в отдельный пункт, чтобы этот выполнялся предсказуемо быстро.

**Глубокая очистка обновлений Windows**
Старые обновления, предыдущие установки Windows, файлы ESD и оптимизации доставки, плюс сжатие хранилища компонентов WinSxS через DISM. Освобождает больше всего места (часто 3-10 ГБ), но работает долго — обработку ведёт `TiWorker.exe`. Не входит в рекомендуемый набор, отмечается вручную.

**Очистка старых точек восстановления**
Удаляет старые теневые копии, оставляя самую свежую.

### Проверка и оптимизация

**Проверка системы: `sfc /scannow` + DISM RestoreHealth**
Проверка и восстановление целостности системных файлов. Занимает 10-30 минут, в рекомендуемый набор не входит.

**Оптимизация диска C**
Тип диска определяется автоматически: для SSD выполняется TRIM, для HDD — полная дефрагментация.

**Проверка скорости интернет-соединения**
Через Speedtest CLI, если `speedtest.exe` лежит рядом с программой, иначе резервным способом — скачиванием тестового файла.

### Настройки системы

**Электропитание: схема «Высокая производительность»**
Включает схему и дополнительно запрещает системе засыпать, гасить экран и отключать диски при простое, а также отключает выборочную приостановку USB на уровне схемы питания.

**Визуальные эффекты: быстродействие**
Отключает анимации, тени и прозрачность, но оставляет включённым сглаживание экранных шрифтов (ClearType).

**Отключить брандмауэр во всех профилях**
Domain, Private, Public. Прежнее состояние сохраняется в бэкап.

**Отключить ненужные службы Windows**
Безопасный набор из 13 служб: факс, индексирование поиска, телеметрия, удалённый реестр и похожие. Не трогает сеть, печать, звук и USB. Кнопка «Подробнее» раскрывает список, где каждую службу можно включить или отключить по отдельности — изменение применяется сразу, без запуска пункта.

**Отключить энергосбережение USB-портов**
Снимает галочку «Разрешить отключение этого устройства для экономии энергии» у всех USB-контроллеров и концентраторов через WMI, включает машинный запрет выборочной приостановки USB и прописывает соответствующие значения на уровне драйвера. Нужно, чтобы не отваливались сканеры штрихкодов, чековые принтеры и прочая USB-периферия.

## Бэкап и восстановление

Перед изменением настроек прежнее состояние пишется в `sclean_backup.json`. Кнопка «Бэкап» открывает диалог, где можно выбрать, что именно возвращать:

- электропитание — схема и тайм-ауты сна, экрана, дисков, USB;
- брандмауэр — состояние трёх профилей;
- визуальные эффекты;
- службы Windows — прежний тип запуска каждой службы;
- энергосбережение USB-портов — состояние по каждому устройству;
- автозапуск приложений — для бэкапов старых версий.

> Удалённые файлы не восстанавливаются — это необратимая операция.

## Отчёты

После каждого запуска в папку `Рабочий стол\sclean` пишется отчёт `sclean_ГГГГ-ММ-ДД_ЧЧММСС.txt`: итог сверху (сколько пунктов выполнено, сколько освобождено, сколько заняло), затем построчно по каждому пункту — что именно очищено, включено или отключено и почему. Хранятся последние 30 отчётов, старые удаляются автоматически.

Освобождённое место считается как сумма того, что пункты измерили сами при удалении файлов. Объём, освобождённый встроенной «Очисткой диска» Windows, в эту сумму не входит — cleanmgr не сообщает его программам.

## Обновление

Кнопка «Проверить обновление» смотрит последний релиз на GitHub и предлагает скачать и установить его. Программа заменяет свой exe и перезапускается сама.

---

## Сборка из исходников

Нужен Python 3 и PyInstaller:

```
pip install pyinstaller
```

В папке с проектом:

```
pyinstaller sclean.spec
```

Готовый `sclean.exe` появится в папке `dist`. Иконка, логотип и настройки сборки (включая запрос прав администратора) уже прописаны в `sclean.spec`, дополнительные ключи не нужны.

Релизы собираются автоматически через GitHub Actions при пуше тега вида `v1.2.3` — см. `.github/workflows/release.yml`.

## Если иконка отображается старой

Windows кэширует иконки. После обновления файла иконки:

```
ie4uinit.exe -show
```

Либо перезапустить проводник в диспетчере задач.
